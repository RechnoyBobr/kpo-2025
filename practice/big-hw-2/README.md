# Система проверки на плагиат

## Архитектура проекта

Проект представляет собой микросервисную архитектуру, состоящую из двух основных сервисов:

### 1. FileStoring Service
Сервис отвечает за хранение файлов и вычисление их хешей. Основные компоненты:
- Хранение файлов в файловой системе
- Вычисление хешей предложений для каждого файла
- Предоставление API для загрузки файлов и получения их хешей

### 2. File Analysis Service
Сервис отвечает за анализ файлов на плагиат. Основные компоненты:
- Получение хешей файлов от FileStoring Service
- Сравнение хешей для определения схожести текстов
- Предоставление API для проверки файлов на плагиат

## Технологии

- Java 21
- Spring Boot
- PostgreSQL
- Docker
- Docker Compose
- Liquibase для управления схемой базы данных
- Swagger для API документации

## Запуск проекта

1. Запустите проект с помощью Docker Compose:
```bash
docker-compose up -d
```

## Доступ к Swagger UI

После запуска проекта, Swagger UI доступен по следующим URL:

- FileStoring Service: http://localhost:8080/swagger-ui.html

## Структура базы данных

### FileStoring Service
- Таблица `files` - информация о загруженных файлах
- Таблица `file_hashes` - хеши предложений для каждого файла

### File Analysis Service
- Таблица `analysis_results` - результаты проверки на плагиат
